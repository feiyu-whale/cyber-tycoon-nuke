# 🎲 赛博地产大亨：核爆版
### Cyber Tycoon: Nuke Edition

> A Monopoly variant with gacha cards, star-upgrades, and a nuclear ending.
> 一个「抽卡升星 + 核弹定胜负」的大富翁变种。

---

## 🎯 四大核心卖点

### 1. 🚀 告别膀胱局，核弹定胜负
传统大富翁最折磨人的就是后期互相耗时间。本作引入自走棋机制，集齐 **5 张三星卡**，直接引爆「**核弹**」强行结算，按经济排名，谁先合出谁就是唯一真神！

> 彩蛋：任意一张卡合出 **四星（27 张同名）**，同样直接引爆核弹。触发者**绝对第一，优先级高于一切代码**——哪怕触发那一刻他刚好破产，也强制获胜。

### 2. 📈 百分比经济学，神仙打架
地价、过路费、税费全部引入百分比和指数级增长。开局一万，后期几百亿，数字缩写全自动（万 / 亿 / 万亿），体验极致的通胀快感。

### 3. 🃏 武将神明齐出，技能满天飞
关羽夺地、财神爷暴富、穷神附体、强制拆迁。全局限量的机制卡，抽到全服播报。

### 4. ⚖️ 绝对的拍卖法则
还原最正统的大富翁强制拍卖机制。不要的地皮？直接强制全场竞价，让 AI 和你体验真实的资本博弈。

## 🕹️ 玩法速览

| 系统 | 说明 |
|---|---|
| **108 星宿** | 踩中机会 / 命运格，天罡 36 + 地煞 72 随机降临 |
| **武将卡** | 10 张，偏收益（夺地 / 群伤 / 再掷 / 移动） |
| **神明卡** | 10 张，正负兼备（送钱 / 扣钱 / 进监狱 / 平分现金） |
| **机制卡** | 8 张，每种**全局限量 4 张**，抽到**全服播报**，可存进卡袋**手动使用** |
| **升星** | 同名 3 张 → 二星（×2）｜9 张 → 三星（×4）｜27 张 → 四星（×10） |
| **核弹** | 五张三星 或 任意四星 → 强制夺冠，本局结束 |
| **卡袋** | 机制卡抽到自动存入，自己判断时机手动点用 |
| **彩票站** | 10% 中大奖，其余领安慰奖 |

## 📜 数值设计原则

> 「开局能买最贵的，那还玩什么呢？」

- **开局资金** 10,000 —— 够买三块普通地，买不起最贵的
- **地价区间** 3,600 → 48,800（最贵是开局的 5 倍，得攒）
- **基础过路费** 1,000 起 —— 「几百块是挠痒痒」
- **盖房成本** 越贵的地越贵 —— 最贵档 180,000 一栋
- **税费** 百分比 + 保底，后期越富交得越狠
- **卡牌金额** 固定值 or 现金比例，取高者，后期自动跟着资产涨

整体节奏：**前期紧 → 中期赌 → 后期爽**。
